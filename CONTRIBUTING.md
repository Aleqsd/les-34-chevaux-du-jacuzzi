# Viens mettre ton grain de folie ✳

Le QG des 34 Chevaux du Jacuzzi accueille les contributions : une animation, une amélioration mobile, un bug corrigé, une idée d’activité ou une interface plus accessible.

1. Ouvre une issue avec le problème ou l’idée. Pour un bug, indique ton navigateur, la taille d’écran et les étapes pour le reproduire.
2. Forke le dépôt, crée une branche et suis le démarrage local du README.
3. Garde les changements centrés sur un sujet. Joins une capture ou une courte vidéo pour une modification visuelle.
4. Lance la vérification TypeScript et le build. Pour un changement des données, utilise les tests locaux documentés.
5. Ouvre une pull request en expliquant le comportement obtenu et ce que tu as vérifié.

## Notre ligne de conduite

- Une expérience généreuse en effets, mais rapide sur mobile. Les préférences `prefers-reduced-motion` doivent être respectées.
- Un vrai retour visible après chaque action, avec une erreur réessayable si la connexion échoue.
- Pas de spoilers de films. Ne renvoie pas de synopsis dans l’API.
- Identité par prénom libre : plusieurs votes du même prénom sont autorisés. Ne présente pas le nombre de votes comme un nombre de personnes.
- Les présences aux rendez-vous sont explicites et séparées des votes.
- Les commentaires sont du texte brut. Ne rends pas de HTML fourni par les visiteurs.
- N’ajoute jamais de clé API, token, fichier `.env`, base de données ou données personnelles de production au dépôt.
- Toute évolution du stockage passe par une nouvelle migration ; ne modifie pas une migration déjà appliquée.

Les discussions doivent rester accueillantes. Explique tes choix, accepte les retours et aide les autres à reproduire les problèmes.

## Premières contributions

Quelques pistes accessibles : navigation au clavier, corrections de textes, amélioration du contraste, performance des animations et tests des petits écrans. Une proposition claire dans les issues est déjà une contribution utile.
